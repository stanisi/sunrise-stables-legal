Data deletion request

Sunrise Stables (com.stanisi.sunrisestables)

What this is

Use this page to ask us to delete analytics and related game data tied to your copy of Sunrise Stables. This is free. We will confirm by email when the request is complete, usually within 30 days.

What we can delete

  • GameAnalytics events and identifiers for your in-app User ID (gameplay, progression, resource events).
  • Cloud save we stored via Google Play Games (progress snapshot named for Sunrise Stables), if we can match it to your request.

We cannot erase, from this form:

  • Google Play purchase records (those stay with Google).
  • Your Google account itself, or Play Games profile — manage those in your Google Account.
  • The copy of the game still on your device until you uninstall it (local save lives on the phone).

How to request deletion

  1. Open Sunrise Stables → Settings (gear) → copy the User ID.
  2. Email us from an address we can reply to.
  3. Use the subject Sunrise Stables data deletion.
  4. Paste the User ID. Optional: Google account email if you used Play Games sign-in / cloud save, and whether you also want cloud save removed.

Email a deletion request

If you cannot open the app, say so in the email and include the Google account you use on the Play Store. We may ask one follow-up question so we do not delete the wrong player.

After you write

We will stop using that User ID for analytics where we control it, ask GameAnalytics to erase the corresponding records, and delete our Play Games snapshot for this game if we can identify it. Uninstall the app to clear the on-device save.
